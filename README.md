# Proyecto 2 - 3101 - Programación Avanzado en Web - UNED
Estos los archivos entregables del proyecto  2 de la materia 3101 Programación Avanzada en Web de la UNED
Para la elaboración este proyecto se utilizo .NET Core 10

# Instrucciones
Este proyecto no cuenta con ninguna particularidad, unicamente decargar los archivos y ejecutar desde el Visual Studio, ya que el archivo slnx se encuentra en el repositorio también, ademas desde restaurar los paquetes NuGet.

Para la conexión a base de datos se debe modificar el archivo appsettings.json con los credenciales necesarios, ademas la aplicación fue creada utilizando Entity Framework asi que unicamente corriendo el comando "dotnet ef database update" desde la consola se podran create tanto las tablas como unos datos default.
